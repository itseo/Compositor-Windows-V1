# Windows V1 scope

V1 means **a useful image editor**, not feature parity with Photoshop or the macOS upstream.

## Must have

- new/open/save `.comp`
- PNG/JPEG/WebP import/export
- layer add/delete/duplicate/rename/reorder
- folders
- visibility and opacity
- move/scale/rotate/flip
- masks
- key blend modes
- zoom/pan/fit
- undo/redo
- brush + erase
- crop
- rectangle/ellipse/lasso selections
- basic Levels, Curves, Hue/Saturation, Exposure and Blur
- text
- basic shapes
- stable external project reload for agent workflows

## Nice to have if schedule permits

- clipping masks
- layer effects
- magic wand
- clone stamp
- PSD baseline import

## Deferred

- Camera Raw parity
- advanced object/subject AI selection
- content-aware fill parity
- extreme large-document parity
- CMYK
- full PSB
